# Rev Idle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-file browser idle game faithfully cloning the Revolution stage of *Revolution Idle* (circles → ascension → prestige → promotions → Infinity finale).

**Architecture:** Source is split into focused files under `src/` and inlined by `build.mjs` into one `index.html`. `src/engine.js` is pure game logic (no DOM) usable from Node tests and the browser (`window.Engine`). `src/render.js` draws the neon orbit canvas (`window.Renderer`). `src/ui.js` owns the DOM panel, game loop, save/load and offline progress.

**Tech Stack:** Vanilla JS (ES2020), Canvas 2D, Node ≥18 `node:test` for tests, no dependencies.

**Spec:** `docs/superpowers/specs/2026-09-23-rev-idle-design.md`

## Global Constraints

- No npm dependencies. No bundler. `node build.mjs` produces `index.html`.
- `index.html` must NOT contain `<!doctype>`, `<html>`, `<head>` or `<body>` tags (Artifact publish wraps it). It starts with `<title>Rev Idle</title>` then `<style>`.
- External resources: only Google Fonts stylesheet (`https://fonts.googleapis.com/css2?...`) — nothing else external.
- Single dark look (deliberate): `:root { color-scheme: dark }`, `html, body { height: 100% }`, `body` has explicit background token. No light theme blocks.
- Must work at 400px width with ≥16px side gutter and no horizontal page scroll; respect `prefers-reduced-motion`.
- `alert/confirm/prompt` are unavailable — confirmations are in-page.
- `localStorage` access always wrapped in try/catch; game must run without it.
- All large quantities stored as **log10** numbers (score, colour mults, mult gain, per-revolution income, costs). `-Infinity` means zero.

## Shared Engine API (contract for all tasks)

```js
Engine.CIRCLES  // array of 10: { name, color, initCost, costMult, baseSpeed }
Engine.INFINITY_LOG // Math.log10(1.79e308)
Engine.newState()                    // -> State
Engine.tick(state, dtSeconds)        // mutates; returns { laps: number[] } laps completed per circle this tick
Engine.simulate(state, seconds)      // offline: repeated tick() in steps ≤ 1s; returns { scoreLogBefore, scoreLogAfter }
Engine.lapsPerSec(state, i)          // number
Engine.perRevLog(state)              // log10 score per lap
Engine.incomeLog(state)              // log10 score per second
Engine.levelCap(circle)              // 100 + 10*ascensions
Engine.costLog(state, i)             // log10 cost of next level of circle i
Engine.buy(state, i, n)              // n: number | 'max'; returns levels bought
Engine.canAscend(state, i) / Engine.ascend(state, i)   // ascend returns boolean
Engine.promoEffects(state)           // { p1, p2, p3, p4 } (p3 = ascension power)
Engine.pendingPrestige(state)        // { pMult, pExp }
Engine.canPrestige(state) / Engine.prestige(state)
Engine.promoXp(state)                // integer
Engine.canPromote(state, k) / Engine.promote(state, k)   // k in 0..3
// ascend / prestige / promote / goInfinite all return true if performed, false if not allowed (no state change)
Engine.canInfinity(state) / Engine.goInfinite(state)
Engine.serialize(state) -> string ; Engine.deserialize(str) -> State (throws Error('Invalid save') on bad input)
Engine.fmtLog(log10value) -> string  // "0", "1,234", "123,456", "1.23e6"...
Engine.logAdd(a, b)                  // log10(10^a + 10^b)
```

State shape:

```js
{
  v: 1,
  scoreLog: -Infinity,
  circles: [ { unlocked, level, bought, ascensions, multLog, multGainLog, progress, laps } x10 ],
  pMult: 1, pExp: 1,
  prestigeReqLog: 10,          // score log needed to prestige (max(10, score log at last prestige))
  promo: [0, 0, 0, 0],
  ip: 0, infinities: 0,
  stats: { totalLaps: 0, prestiges: 0, promotions: 0, playTime: 0, bestScoreLog: -Infinity },
  savedAt: 0                   // ms timestamp, set by UI
}
```

Circle fresh values: `{ unlocked: i===0, level: i===0 ? 5 : 0, bought: 0, ascensions: 0, multLog: 0, multGainLog: -2, progress: 0, laps: 0 }`.

### Task 1: Engine core — circles, costs, buying, tick, formatting

**Model:** sonnet

**Files:**
- Create: `src/engine.js`, `test/engine.test.js`, `package.json`

**Interfaces:**
- Produces: `CIRCLES, INFINITY_LOG, newState, tick, simulate, lapsPerSec, perRevLog, incomeLog, levelCap, costLog, buy, promoEffects, fmtLog, logAdd` per the Shared Engine API.

Rules:
- `CIRCLES` table (name, color, initCost, costMult, baseSpeed):
  Red `#ff3b4f` 4 1.20 0.2; Orange `#ff8a2a` 100 1.24 0.1; Yellow `#ffd93b` 1e3 1.28 1/15; Green `#4dff6a` 1e4 1.32 0.05; Turquoise `#2affc6` 1e6 1.36 0.04; Cyan `#2ad9ff` 1e9 1.40 1/30; Blue `#3b6bff` 1e12 1.44 1/35; Purple `#a24dff` 1e15 1.48 0.025; Pink `#ff4dd2` 1e18 1.52 1/45; White `#f4f1ff` 1e27 1.56 0.02.
- `promoEffects`: `p4 = 1 + 0.05*L4^0.48; p1 = p4*(floor(L1^1.5)+1); p2 = p4*(1+sqrt(L2)); p3 = p4*(10 + L3^0.82)` with `L = state.promo[k]`.
- `lapsPerSec(s,i) = unlocked ? level*baseSpeed*p2 : 0`.
- `costLog(s,i)`: with `a = ascensions`, `m = costMult`: `log10(init) + Σ_{k<a} (100+10k)*log10(m+0.1k) + level*log10(m+0.1a)`.
- `buy(s,i,n)`: repeatedly while count < n (or unlimited for 'max'), level < cap and `scoreLog >= costLog`: subtract cost (`scoreLog = logSub(scoreLog, cost)`, with exact-equal giving -Infinity), level++, bought++. After buying, if `bought >= 5` and circle i+1 exists and is locked, unlock it (level 0). Return count. Unlocked circles must be `unlocked`.
- `perRevLog(s) = pExp * (Σ unlocked circles multLog + log10(pMult))`.
- `incomeLog(s) = perRevLog(s) + log10(Σ lapsPerSec)` (-Infinity if sum is 0).
- `tick(s, dt)`: for each unlocked circle: `progress += lps*dt; n = floor(progress); progress -= n; laps += n`; if n>0: `multLog = logAdd(multLog, log10(n) + multGainLog + log10(p1))`. After all circles: `N = Σ n`; if N>0: `scoreLog = logAdd(scoreLog, log10(N) + perRevLog(s))`. `stats.totalLaps += N`, `stats.playTime += dt`, `stats.bestScoreLog = max(...)`. Return `{ laps: [n per circle] }`.
- `simulate(s, seconds)`: loop `tick(s, min(1, remaining))`; return before/after score logs.
- `fmtLog(x)`: `-Infinity` → `"0"`; if `x < 6` → `Math.floor(10**x + 1e-9)` with `toLocaleString('en-US')`; else mantissa/exponent `"1.23e45"` (mantissa 2 decimals; handle mantissa rounding to 10.00 → bump exponent).

### Task 2: Engine layers — ascension, prestige, promotions, infinity, save

**Model:** sonnet · **Depends on:** Task 1

**Files:**
- Modify: `src/engine.js`
- Modify: `test/engine.test.js` (append)

**Interfaces:**
- Consumes: Task 1 exports.
- Produces: `canAscend, ascend, pendingPrestige, canPrestige, prestige, promoXp, canPromote, promote, canInfinity, goInfinite, serialize, deserialize`.

Rules:
- `canAscend`: unlocked and `level >= levelCap`. `ascend`: level=5, ascensions++, `multGainLog += log10(p3)`; keep multLog. Return true/false.
- `pendingPrestige(s)`: if `scoreLog < 3` → `{pMult:1,pExp:1}`; else `pMult = 2.56 * (scoreLog-3)**2.25`, `pExp = 1 + max(0, scoreLog-5)/225`. (Tunable constants live in `const TUNE = { pMultBase: 2.56, pMultPow: 2.25, pExpDiv: 225, prestigeMinLog: 10, promoMin: 1000, promoPow: 0.75 }` exported as `Engine.TUNE`.)
- `canPrestige`: `scoreLog >= max(TUNE.prestigeMinLog, prestigeReqLog)`. `prestige`: `pMult = max(pMult, pending.pMult)`, `pExp = max(...)`, `prestigeReqLog = scoreLog`, `stats.prestiges++`, reset run (score -Infinity, circles fresh).
- `promoXp(s) = floor((max(pMult, pendingPrestige.pMult if canPrestige else 0)/1000)**0.75)` — 0 if below 1000.
- `canPromote(s,k)`: `promoXp > promo[k]`. `promote`: `promo[k] = xp`, reset run, `pMult=1, pExp=1, prestigeReqLog=10`, `stats.promotions++`.
- `canInfinity`: `scoreLog >= INFINITY_LOG`. `goInfinite`: `ip++, infinities++`, then everything else reset to `newState()` values except `stats`, `ip`, `infinities`.
- `serialize`: `btoa(JSON.stringify(state))` with `-Infinity` encoded as the string `"-inf"` (use a replacer/reviver). In Node use `Buffer` when `btoa` absent. `deserialize`: reverse; validate `v === 1` and `circles.length === 10`, else throw `Error('Invalid save')`; merge onto `newState()` so missing fields default.

### Task 4: Canvas renderer

**Model:** sonnet · **Depends on:** Task 1 (API/state shape only; can run in parallel with Tasks 2–3)

**Files:**
- Create: `src/render.js`

**Interfaces:**
- Consumes: `Engine.CIRCLES`, `Engine.lapsPerSec`, state shape.
- Produces: `window.Renderer = { create(canvas) -> { draw(state, dt, lapsThisTick /* number[] */), resize() } }`.

Behavior:
- DPR-aware canvas sizing on `resize()` (call from ResizeObserver in UI).
- Background: ink `#07060d` with a faint radial vignette; subtle static starfield (seeded, drawn once to an offscreen canvas).
- Concentric orbits centred; radius for circle i = `rMin + i*(rMax-rMin)/9` with `rMax = 0.46*min(w,h)`, `rMin = 0.08*min(w,h)`. Locked orbits: 1px dashed `rgba(255,255,255,0.06)`. Unlocked: 1.5px track in circle colour at 18% alpha.
- Dot angle = `progress * 2π - π/2` (clockwise from top). Dot radius 4–6px scaled, with `shadowBlur` glow in circle colour; comet trail: arc behind the dot whose length = `min(0.9, lps*0.25)` of a revolution, drawn as gradient-alpha segments (≈24 segments).
- When `lps > 6`: draw a solid glowing ring (track at 70% alpha, pulsing lineWidth) instead of a dot + trail.
- Lap pulse: when `lapsThisTick[i] > 0`, spawn an expanding ring ripple at that orbit (fade over 0.5 s, max 40 live pulses, cap one spawn per circle per 100 ms).
- Centre: small text of `Engine.fmtLog(state.scoreLog)` is NOT drawn here (UI owns numbers); draw a soft core glow tinted by the highest unlocked circle.
- `prefers-reduced-motion: reduce` → no ripples, no pulsing.
- No allocations per frame beyond small arrays; must hold 60 fps with 10 rings.

**`src/ui.js` behavior:**
- Boot: load save from `localStorage['revidle.save.v1']` via `Engine.deserialize` (try/catch; on failure start new). If `savedAt` present, offline seconds = `min((Date.now()-savedAt)/1000, 8*3600)`; if > 10 s run `Engine.simulate` and show a "While you were away" modal: time away, score gained (`fmtLog`).
- Support hot reload: `window.claude?.hot?.snapshot?.(() => ({ save: Engine.serialize(state) }))`; boot via `window.claude?.hot?.ready ? window.claude.hot.ready(start) : start(window.claude?.hot?.data ?? {})`, where `start(data)` prefers `data.save` over localStorage.
- Loop: rAF; `dt = min(elapsed, 0.25)`; `Engine.tick`, `renderer.draw(state, dt, laps)`; DOM text updates throttled to 10 Hz; tabs re-render only on structural change (unlock, ascension, tab switch) — otherwise update text nodes in place.
- Autosave every 10 s and on `visibilitychange` hidden (set `savedAt = Date.now()`).
- Multbar: for each unlocked circle a chip `×{fmtLog(multLog)}` coloured by circle; then grey `P ×{pMult}` and `^{pExp.toFixed(3)}` when pExp > 1.
- Score box over canvas bottom-left: big score in Unbounded, income `/s` in mono.
